## SupportAI क्या है?

SupportAI एक फ़ुल-स्टैक प्लेटफ़ॉर्म है जो AI-चलित ग्राहक समर्थन चैटबॉट बनाने में मदद करता है। प्रत्येक एजेंट का अपना व्यक्तित्व, AI प्रदायक (Google Gemini या OpenAI), API कुंजी और ज्ञान आधार होता है — डेटा और लागत कंट्रोल करने के पूरा नियंत्रण के साथ।

व्यवसाय, डेवलपर और SaaS उत्पादकों के लिए निर्मित — जो तृतीय पक्ष के चैट प्लेटफ़ॉर्म पर ग्राहक डेटा नहीं भेजना चाहते बल्कि स्मार्ट, ब्रांड-मिलाने वाले समर्थन चाहिए। आपकी API कुंजी, आपका ज्ञान, आपका बुनियादी ढाँचा।

## अपना पहला एजेंट बनाएं

एजेंट **डैशबोर्ड** से बनाएं और प्रबंधित किए जाते हैं। साइन इन करें, फिर **New agent** पर क्लिक करें। प्रत्येक एजेंट पूरी तरह से स्वाधीन होता है — अपना प्रदायक, मॉडल और API कुंजी — इसलिए आप एक अकाउंट में विभिन्न प्रदायकों का उपयोग कर सकते हैं।

निर्माण प्रवाह एक ४-चरण के विज़ार्ड से बना है:

### चरण 1: मूल जानकारी

अपने एजेंट को ब्रांड-मिलाने के लिए एक अवसर दें:

- **एजेंट का नाम** — एक आंतर्जातीय लेबल जो बाद में पहचान आएगा (जैसे "Acme Returns")
- **व्यवसाय का नाम** + **उद्योग** — एजेंट के टोन और शब्दावली की नींव रखता है
- **समर्थन ईमेल** — जब बॉट इंसान के पास हस्तांतरित होता है, तो भ्रमणकर्ता को दिखाई देता है
- **व्यवसाय विवरण** — आप क्या प्रदान करते हैं, आप किसको लक्ष्य करते हैं, और आप क्या अलग करते हैं एक छोटा अनुच्छेद

### चरण 2: पर्सोना

एजेंट को अपनी टीम के सदस्य की तरह महसूस कराएं:

- **बॉट का प्रदर्शन नाम** — चैट विंडो में दिखता नाम (जैसे "Aria", "Max")
- **संचार टोन** — मैत्रीपूर्ण (Friendly), पेशेवर (Professional), अनौपचारिक (Casual), औपचारिक (Formal), सहानुभूतिपूर्ण (Empathetic), संक्षिप्त (Concise), मनोरंजक (Playful), या तकनीकी (Technical) में से चुनें
- **व्यक्तित्व और निर्देश** — स्वतंत्र मार्गदर्शन: भ्रमणकर्ता को कैसे अभिवादन करेगा, किन विषयों से बचेगा, कोने के केस कैसे संभालेगा आदि

### चरण 3: मॉडल और कुंजी

एजेंट के दिमाग का चयन करें:

- **प्रदायक** — Google Gemini या OpenAI
- **मॉडल** — जैसे Gemini 2.0 Flash या GPT-4o mini
- **API कुंजी** — अपने प्रदायक के कंसोल से एक कुंजी पेस्ट करें। प्रत्येक एजेंट की अपनी कुंजी होती है, इसलिए आप प्रति एजेंट लागत ट्रैक कर सकते हैं।

### चरण 4: समीक्षा

सारांश की समीक्षा करें, फिर निर्णय लें:

- **अभी लाइव करें** टॉगल करके एजेंट को एम्बेडेड साइट्स पर तुरंत प्रकाशित करें — या ड्राफ्ट में छोड़ दें और बाद में कॉन्फ़िगर करें।

> एक बार बन जाने के बाद, आप **Config** खोलकर **draft** और **live** स्थिति के बीच स्विच कर सकते हैं। भ्रमणकर्ता एम्बेड विजेट के माध्यम से चैट कर सकते हैं केवल जब एजेंट **live** हो।

## ज्ञान जोड़ें

एक एजेंट उतना स्मार्ट होता है जितनी जानकारी आप उसे देते हैं। एजेंट बनाने के बाद उसके **Knowledge** टैब खोलें और स्रोत जोड़ें। आप किसी भी संयोजन का उपयोग कर सकते हैं:

| स्रोत      | फॉर्मैट                 | कब उपयोग करें                                        |
| ---------- | ----------------------- | ---------------------------------------------------- |
| **Text**   | Plain text              | FAQ, नीतिमाला, उत्पाद विवरण या रिटर्न कारण जोड़ें    |
| **URL**    | Web page URL            | सहायता लेख, डॉक्स पृष्ठ या उत्पाद पृष्ठ स्क्रैप करें |
| **File**   | PDF, DOCX, TXT, MD, CSV | मैनुअल, स्प्रेडशीट या दीर्घ डॉक्यूमेंट अपलोड करें    |
| **Notion** | Page or database ID     | आपके Notion कार्यस्थल के सामग्री का संकेत लगाएं      |

### एक स्रोत जोड़ना

1. एजेंट खोलें → **Knowledge** टैब।
2. स्रोत प्रकार चुनें: **Text**, **URL**, **File**, या **Notion**।
3. सामग्री भरें और **Add to knowledge base** पर क्लिक करें।
4. दस्तावेज़ इंडेक्स करा जाएगा और नीचे सूची में इसकी स्थिति अपडेट होगी:

| स्थिति         | इसका अर्थ क्या है                                           |
| -------------- | ----------------------------------------------------------- |
| **ready**      | प्रश्नों के उत्तर देने के लिए इंडेक्स किया गया और उपलब्ध है |
| **processing** | अभी तक विभाजित और एम्बेड किया जा रहा है — फिर से जांचें     |
| **error**      | कुछ गड़बड़ हुई — फिर से जोड़ें या छोटा फ़ाइल आजमाएं         |

> Notion का उपयोग करने के लिए एक बार **Plugins** में एकीकरण टोकन सेट करें। अपनी एकीकरण को जिस page या database का संकेत लगाना चाहते हैं, उसमें आमंत्रित करें (share → invite → आपकी एकीकरण का नाम)।

प्रत्येक ज्ञान स्रोत स्वचालित रूप से टुकड़ों में विभाजित करके खोज योग्य बनाया जाता है, ताकि एजेंट आपके प्रश्न के सबसे प्रासंगिक उत्तर ढूँढ सके।

## आपकी साइट पर एम्बेड करें

जब एजेंट **live** हो जाता है, तो आप इसे किसी भी वेबसाइट पर रख सकते हैं:

1. एजेंट खोलें → **Embed** टैब।
2. एकल script टैग कॉपी करें।
3. अपनी साइट के HTML में जोड़ें, `</body>` टैग बंद करने से पहले।
4. सहेजें और डिप्लॉय करें — चैट विजेट नीचे-दाएँ कोने में दिखाई देगा।

```html
<script src="https://your-domain.com/chat_bot.js" data-bot-id="MONGODB_OBJECT_ID"></script>
```

यह स्क्रिप्ट एक स्वतंत्र **5KB वैनिला जावास्क्रिप्ट फ़ाइल** है — कोई बिल्ड स्टेप नहीं, कोई निर्भरता नहीं, कोई फ्रेमवर्क नहीं चाहिए। यह किसी भी स्थिर या गतिशील साइट (WordPress, Shopify, Next.js, साधारण HTML — जो भी) पर काम करता है।

विजेट स्वचालित रूप से:

- एजेंट के **Appearance** टैब में सेट **accent color**, **display name**, **avatar**, और **welcome message** का उपयोग करता है
- एक गुप्त सत्र ID बनाता है (`localStorage` में संग्रहीत) जिससे बहु-मोड़की चैट सत्र पृष्ठ लोड पर भी बना रहते हैं
- प्रतिक्रियाशील है — मोबाइल पर पूरी चौड़ाई, डेस्कटॉप पर कॉम्पैक्ट

**प्रतिक्रियाशील आकार:** मोबाइल पर (≤480px) पूरी चौड़ाई, टैबलेट पर 380px, डेस्कटॉप पर 400×560।

## डैशबोर्ड गाइड

आपकी सबसे ज़रूरी सब कुछ — एजेंट बनाना, ट्यून करना और निगरानी करना — यहाँ **डैशबोर्ड** में है।

### खाता-स्तर के दृश्य

| पृष्ठ                            | आप क्या देखेंगे                                                                                                                                                      |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Overview** (`/dashboard`)      | सभी एजेंट्स का एक स्नैपशॉट: कुल एजेंट, लाइव संख्या, बातचीत, संदेश, 14-दिवसीय संदेश चार्ट, आपके शीर्ष एजेंट और हालिया बातचीत। ठीक यहीं से **New agent** से शुरू करें। |
| **Agents** (`/dashboard/agents`) | आपके द्वारा बनाए गए प्रत्येक एजेंट का एक ग्रिड। प्रत्येक कार्ड पर स्थिति (live/draft) दिखती है और एक तेज़ **Open** लिंक। तीन-बिंदु मेन्यू से एजेंट डिलीट करें।       |

### प्रति-एजेंट दृश्य

कोई भी एजेंट खोलें — टैब बार दिखेगा:

| टैब               | आप यहाँ क्या करते हैं                                                                                                                                 |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Overview**      | तेज़ आँकड़े: बातचीत संख्या, संदेश संख्या, अंतिम सक्रिय समय, और प्रमुख विवरण (प्रदायक, मॉडल, API कुंजी स्थिति)।                                        |
| **Playground**    | ब्राउज़र में एजेंट का परीक्षण करें। संदेश भेजें और प्रतिक्रिया पढ़ें — बिना किसी बातचीत इतिहास को सहेजे।                                              |
| **Config**        | एजेंट का नाम, स्थिति (draft/live), व्यावसायिक जानकारी, व्यक्तित्व, प्रदायक, मॉडल और API कुंजी संपादित करें। एजेंट डिलीट करने के लिए भी यहीं।          |
| **Knowledge**     | ज्ञान स्रोत जोड़ें, ब्राउज़ करें और हटाएँ (Text, URL, File, Notion)। प्रत्येक दस्तावेज़ को `processing` से `ready` तक प्रगति देखें।                   |
| **Appearance**    | एम्बेड विजेट की दिखावट कस्टमाइज़ करें: accent color, display name, avatar URL और welcome message। एक लाइव प्रिव्यू आपके टाइपिंग के साथ अपडेट होता है। |
| **Embed**         | इस एजेंट का `<script>` स्निपेट कॉपी करें और पुष्टि करें कि यह **live** है।                                                                            |
| **Conversations** | इस एजेंट की सभी भ्रमणकर्ता सत्र ब्राउज़ करें। एक सत्र खोलकर पूरा अनुवाद पढ़ें।                                                                        |

## कैसे काम करता है

1. **एजेंट बनाएं** — एक नाम, व्यावसायिक संदर्भ और व्यक्तित्व दें।
2. **प्रदायक चुनें** — Google Gemini या OpenAI चुनें, और एजेंट की API कुंजी पेस्ट करें।
3. **ज्ञान जोड़ें** — फाइलें अपलोड करें, टेक्स्ट पेस्ट करें, URL स्क्रैप करें, या Notion कनेक्ट करें।
4. **Playground** में परीक्षण करें — व्यक्तित्व और टोन ठीक से काम कर रहा है या नहीं यह जाँचें।
5. **Embed** — एक `<script>` टैग कॉपी करके अपनी साइट पर रखें।

चैट के समय, एजेंट आपके कॉन्फ़िगर किए गए व्यक्तित्व (सिस्टम प्रॉम्प्ट) को आपके स्रोतों से सबसे प्रासंगिक ज्ञान के साथ जोड़ता है और आपके चुनिंदा प्रदायक के माध्यम से जवाब देता है — सब कुछ आपके अपने स्टैक में।
