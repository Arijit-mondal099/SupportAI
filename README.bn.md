## SupportAI কী?

SupportAI হল একটি ফুলস্ট্যাক প্ল্যাটফর্ম যা AI-চালিত গ্রাহক সমর্থন চ্যাটবট তৈরি করতে সহায়তা করে। প্রতিটি এজেন্টের নিজস্ব আন্তর্ভুক্তিকরণ, AI প্রদাতা (Google Gemini অথবা OpenAI), API কী এবং জ্ঞান ভিত্তা থাকে — ডেটা ও খরচ নিয়ন্ত্রণের পূর্ণ নিয়ন্ত্রণ দিয়ে।

ব্যবসা, ডেভেলপার এবং SaaS পণ্য উৎপাদনকর্তাদের জন্য তৈরি — যারা তৃতীয় পক্ষের চ্যাট প্ল্যাটফর্মে গ্রাহকের ডেটা পাঠাই না চান কিন্তু স্মার্ট, ব্র্যান্ড-মিলিয়ে যুক্ত সমর্থন চান। আপনার API কী, আপনার জ্ঞান, আপনার অবকাঠামো।

## আপনার প্রথম এজেন্ট গড়ুন

এজেন্টগুলো **ড্যাশবোর্ড**-এ তৈরি এবং পরিচালনা করা হয়। সাইন ইন করুন, তারপর **New agent** ক্লিক করুন। প্রতিটি এজেন্ট সম্পূর্ণ আত্মনির্ভর — নিজস্ব প্রদাতা, মডেল এবং API কী — তাই একটি অ্যাকাউন্টে বিভিন্ন প্রদাতা ব্যবহার করতে পারেন।

তৈরির প্রক্রিয়াটি একটি ৪-ধাপের ওয়্যার্ড:

### স্টেপ 1: মৌলিক তথ্য

আপনার এজেন্টকে ব্র্যান্ড-মিলিয়ে রাখতে একটি সুযোগ দিন:

- **এজেন্টের নাম** — পরে চিনতে পারবেন এমন একটি আন্তর্জাতিক লেবেল (যেমি "Acme Returns")
- **ব্যবসা নাম** + **শিল্প** — এজেন্টের টোন ও প্রযুক্তিতে ভিত্তি রেখে দেয়
- **সমর্থন ইমেল** — যখন বট মানুষের কাছে হস্তান্তর করে, ভিজিটরদের দেখা যায়
- **ব্যবসার বর্ণনা** — আপনি কী অফার করেন, কাকে টার্গেট করেন, আর কী আলাদা করে তোলেন তা একটি সংক্ষিপ্ত অনুচ্ছেদ

### স্টেপ 2: পার্সোনা

এজেন্টকে আপনার দলের অংশের মনে করিয়ে দিন:

- **বটের প্রদর্শন নাম** — চ্যাট উইন্ডোতে দেখা যাবে (যেমি "Aria", "Max")
- **যোগাযোগের টোন** — বন্ধুসুলভ (Friendly), পেশাদার (Professional), সহজাসহজ (Casual), ঔপচারিক (Formal), সহানুভূতিক (Empathetic), সংক্ষেপস্থ (Concise), খেলোয়াড় (Playful), অথবা প্রযুক্তিগত (Technical) থেকে পছন্দ নির্বাচন করুন
- **ব্যক্তিত্ব ও নির্দেশনা** — স্বাধীন নির্দেশনা: ভিজিটরদের কীভাবে অভিবাদন করবে, কোন বিষয় এড়াতে হবে, কীভাবে কোণা কেস হ্যান্ডেল করবে ইত্যাদি

### স্টেপ 3: মডেল ও কী

এজেন্টের মস্তিষ্ক বাছাই করুন:

- **প্রদাতা** — Google Gemini বা OpenAI
- **মডেল** — যেমি Gemini 2.0 Flash বা GPT-4o mini
- **API কী** — আপনার প্রদাতার কন্সোল থেকে একটি কী পেস্ট করুন। প্রতিটি এজেন্টের নিজস্ব কী থাকে, তাই আপনি প্রতি এজেন্টের খরচ ট্র্যাক করতে পারেন।

### স্টেপ 4: পর্যালোচনা

সংক্ষেপণ পর্যালোচনা করুন, তারপর সিদ্ধান্ত নিন:

- **এখনই লাইভ করুন** টগল করে এজেন্টটিকে এম্বেডেড সাইটে সঙ্কেত পাঠাত্মকভাবে প্রকাশ করুন — অথবা টাক সেট করে রাখুন এবং পরে কনফিগার করুন।

> একবার তৈরি হয়ে গেলে, **Config**-এর মাধ্যমে **draft** এবং **live** স্ট্যাটাসের মধ্যে স্যুইচ করতে পারেন। ভিজিটররা এম্বেড উইজেটের মাধ্যমে চ্যাট করতে পারবেন শুধুমাত্র যখন এজেন্টটি **live** হবে।

## জ্ঞান যোগ করুন

একজন এজেন্ট কতটা পরিষ্কার তা আপনার জ্ঞানের ওপর নির্ভর করে। এজেন্ট তৈরি করলে এর **Knowledge** ট্যাব খুলুন এবং সোর্স যোগ করুন। যেকোনো সময় অন্য কোনও সংযোজন ব্যবহার করতে পারেন:

| সোর্স      | ফর্ম্যাট                | কখন ব্যবহার করবেন                                      |
| ---------- | ----------------------- | ------------------------------------------------------ |
| **Text**   | Plain text              | FAQ, নীতিমালা, পণ্যের বিবরণ বা রিটার্ন কারণ আপলোড করুন |
| **URL**    | Web page URL            | সাহায্য নিবন্ধ, ডক্স পেজ বা পণ্য পেজ স্ক্র্যাপ করুন    |
| **File**   | PDF, DOCX, TXT, MD, CSV | ম্যানুয়াল, স্প্রেডশিট বা লম্বা ডকুমেন্ট আপলোড করুন    |
| **Notion** | Page or database ID     | আপনার Notion কর্মস্থলের বিষয়বস্তু ইন্ডেক্স করুন       |

### একটি সোর্স যোগ করা

1. এজেন্টটি খুলুন → **Knowledge** ট্যাব।
2. সোর্সের ধরণ নির্বাচন করুন: **Text**, **URL**, **File**, অথবা **Notion**।
3. বিষয়টি পূরণ করুন এবং **Add to knowledge base**-এ ক্লিক করুন।
4. ডকুমেন্টটি ইন্ডেক্স করা হবে এবং নিচের তালিকায় এর স্ট্যাটাস আপডেট হবে:

| স্ট্যাটাস      | এর অর্থ কী                                                      |
| -------------- | --------------------------------------------------------------- |
| **ready**      | প্রশ্নের উত্তর দিতে ইন্ডেক্স করা ও উপলভ্য                       |
| **processing** | এখনও ভাগ করে এবং এম্বেড করা হচ্ছে — আবার চেক করুন               |
| **error**      | কোনো সমস্যা হয়েছে — পুনরায় যোগ করুন অথবা ছোট ফাইল চেষ্টা করুন |

> Notion ব্যবহার করতে একবার **Plugins**-এ একটি ইন্টিগ্রেশন টোকেন সেট করুন। আপনার ইন্টিগ্রেশনকে যে page বা database ইন্ডেক্স করতে চান, তাতে আমন্ত্রণ জানান (share → invite → আপনার ইন্টিগ্রেশনের নাম)।

প্রতিটি জ্ঞান সোর্স স্বয়ংক্রিয়ভাবে ভাগ করা হয় এবং অনুসন্ধানযোগ্য করা হয়, যাতে এজেন্টটি আপনার প্রশ্নের জন্য সবচেয়ে প্রাসঙ্গিক উত্তর খুজে পায়।

## আপনার সাইটে এম্বেড করুন

যখন এজেন্টটি **live** হবে, তখন এটি যেকোনো ওয়েবসাইটে যোগ করতে পারেন:

1. এজেন্টটি খুলুন → **Embed** ট্যাব।
2. একক script ট্যাগটি কপি করুন।
3. আপনার সাইটের HTML-এ যোগ করুন, `</body>` ট্যাগ বন্ধ করার আগে।
4. সংরক্ষণ এবং ডিপ্লয় করুন — চ্যাট উইজেট নিচে-ডান কোণায় দেখা যাবে।

```html
<script src="https://your-domain.com/chat_bot.js" data-bot-id="MONGODB_OBJECT_ID"></script>
```

এই স্ক্রিপ্টটি একটি স্বাধীন **5KB ভ্যানিলা জাভাস্ক্রিপ্ট ফাইল** — কোনো বিল্ড স্টেপ নেই, কোনো নির্ভরতা নেই, কোনো ফ্রেমওয়ার্ক লাগে না। এটি যেকোনো স্ট্যাটিক বা ডাইনামিক সাইটে (WordPress, Shopify, Next.js, সাধারণ HTML — যেকোনোটাই) কাজ করে।

উইজেটটি স্বয়ংক্রিয়ভাবে:

- এজেন্টের **Appearance** ট্যাবে সেট করা **accent color**, **display name**, **avatar**, এবং **welcome message** ব্যবহার করে
- একটি গোপনীয় সেশন ID তৈরি করে (`localStorage`-এ সংরক্ষিত) যাতে একাধিক ধাপের চ্যাট সেশন রক্ষিত থাকে
- রেস্পনসিভ — মোবাইলে পূর্ণ প্রস্থ, ডেস্কটপে কম্প্যাক্ট

**রেস্পনসিভ স্কেলিং:** মোবাইলে (≤480px) পূর্ণ প্রস্থ, ট্যাবলেটে 380px, ডেস্কটপে 400×560।

## ড্যাশবোর্ড গাইড

আপনার সবচেয়ে দরকারি সব জিনিস — এজেন্ট তৈরি, টিউন এবং নিগরানি করতে — এখানে আছে **ড্যাশবোর্ড**।

### অ্যাকাউন্ট-স্তরের ভিউ

| পৃষ্ঠা                           | আপনি কী দেখবেন                                                                                                                                                                 |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Overview** (`/dashboard`)      | সব এজেন্ট জুড়ে একটি স্ন্যাপশট: মোট এজেন্ট, লাইভ সংখ্যা, কথোপকথন, বার্তা, ১৪-দিনের বার্তা চার্ট, শীর্ষ এজেন্ট এবং সাম্প্রত্য কথোপকথন। এখান থেকেই **New agent** থেকে শুরু করুন। |
| **Agents** (`/dashboard/agents`) | আপনার তৈরি প্রতিটি এজেন্টের একটি গ্রিড। প্রতিটি কার্ডে স্ট্যাটাস (live/draft) দেখা যায় এবং একটি দ্রুত **Open** লিংক। তিন-বিন্দু মেনু থেকে এজেন্ট মুছে ফেলুন।                  |

### প্রতি-এজেন্ট ভিউ

যেকোনো এজেন্ট খুলুন ট্যাব বার দেখা যাবে:

| ট্যাব             | আপনি কী করবেন এখানে                                                                                                                              |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Overview**      | দ্রুত পরিসংখ্যান: কথোপকথন সংখ্যা, বার্তা সংখ্যা, শেষ সক্রিয় সময়, এবং মূল বিবরণী (প্রদাতা, মডেল, API কী স্ট্যাটাস)।                             |
| **Playground**    | ব্রাউজারে এজেন্ট টেস্ট করুন। বার্তা পাঠান এবং প্রতিটি প্রতিটি পড়ুন — কোনো কথোপকথন ইতিহাসে সংরক্ষণ না করে।                                       |
| **Config**        | এজেন্টের নাম, স্ট্যাটাস (draft/live), ব্যবসা তথ্য, ব্যক্তিত্ব, প্রদাতা, মডেল এবং API কী সম্পাদনা করুন। এজেন্ট মুছে ফেলার জন্য এই পৃষ্ঠাটি।       |
| **Knowledge**     | জ্ঞান সোর্স যোগ, ব্রাউজ এবং মুছে ফেলুন (Text, URL, File, Notion)। প্রতিটি ডকুমেন্ট `processing` থেকে `ready` পর্যন্ত অগ্রগতি দেখুন।              |
| **Appearance**    | এম্বেডেড উইজেটের চেহারা কাস্টোমাইজ করুন: accent color, display name, avatar URL এবং welcome message। একটি লাইভ প্রিভিউ টাইপ করা মাত্র আপডেট হয়। |
| **Embed**         | এই এজেন্টের `<script>` স্নিপেট কপি করুন এবং নিশ্চিত করুন যে এটি **live**।                                                                        |
| **Conversations** | এই এজেন্টের সকল ভিজিটর সেশন ব্রাউজ করুন। একটি সেশন খুলে সম্পূর্ণ ট্রান্সক্রিপ্ট পড়ুন।                                                           |

---

## কিভাবে কাজ করে

1. **এজেন্ট তৈরি করুন** — একটি নাম, ব্যবসা প্রসঙ্গ এবং ব্যক্তিত্ব দিন।
2. **প্রদাতা নির্বাচন করুন** — Google Gemini বা OpenAI নির্বাচন করুন, এবং এজেন্টের API কী পেস্ট করুন।
3. **জ্ঞান যোগ করুন** — ফাইল আপলোড করুন, টেক্সট পেস্ট করুন, URL স্ক্র্যাপ করুন, অথবা Notion সংযুক্ত করুন।
4. **Playground**-এ টেস্ট করুন — ব্যক্তিত্ব ও টোন ঠিক আছে কিনা পরীক্ষা করুন।
5. **Embed** — একটি `<script>` ট্যাগ কপি করে আপনার সাইটে যোগ করুন।

চ্যাটের সময়, এজেন্টটি আপনার কনফিগার করা ব্যক্তিত্বকে (সিস্টেম প্রম্পট) আপনার সোর্স থেকে প্রাসঙ্গিক জ্ঞান যুক্ত করে এবং আপনার পছন্দের প্রদাতার মাধ্যমে প্রতিটি প্রতিটি পাঠায় — সবকিছু আপনার নিজস্ব স্ট্যাকে।
